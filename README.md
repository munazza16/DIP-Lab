# Lab Assignment
This repository contains the complete implementation of a 10-step computer vision task using Python, OpenCV, and Matplotlib. The project demonstrates fundamental image processing operations including color space transformations, geometric modifications, and pixel-level analysis.

## Files in this Repository
- index.py: The primary Python script containing the source code for all operations.
- image1.jpeg: The source input image used for processing.
- gray_output.jpg: The generated and saved grayscale output image.

## Implemented Operations
1. Loading the image into the workspace.
2. Rendering the original image using Matplotlib.
3. Extracting and displaying image dimensions.
4. Inspecting and printing specific pixel intensity values at coordinate (100, 100).
5. Converting the default BGR color space into a grayscale matrix.
6. Checking the dimensions of the converted single-channel grayscale image.
7. Visualizing the grayscale representation.
8. Rescaling the image resolution to 300 x 300 pixels.
9. Cropping a specific region of interest using array slicing.
10. Exporting and saving the processed grayscale output locally.
